## 🧭 **Guía paso a paso para tu Portfolio Website**

### 1. 📁 **Estructura de carpetas**
Organiza tu proyecto localmente:

```
portfolio-website/
├── index.html
├── contact.html
├── projects/
│   ├── project1.html
│   ├── project2.html
├── assets/
│   ├── css/
│   │   └── styles.css
│   ├── js/
│   │   └── script.js
│   └── images/
```

---

### 2. 🧱 **HTML básico**
Crea las páginas principales:

#### `index.html` (Página principal)
- Header con tu nombre y navegación
- Sección de presentación
- Galería de proyectos con enlaces a cada uno

#### `contact.html`
- Formulario de contacto con campos: nombre, email, mensaje
- Información adicional (LinkedIn, GitHub, etc.)

#### `projects/project1.html`
- Descripción del proyecto
- Tecnologías usadas (puedes usar íconos o badges)
- Capturas de pantalla o enlaces al repositorio

---

### 3. 🎨 **Estilos con CSS**
En `styles.css`:
- Usa Flexbox o Grid para layout responsivo
- Define una paleta de colores que refleje tu estilo
- Añade hover effects para botones y enlaces

---

### 4. ⚙️ **Interactividad con JavaScript**
Ejemplos de funciones que puedes incluir en `script.js`:
- Modo oscuro 🌙
- Validación del formulario de contacto
- Animaciones al hacer scroll
- Filtro de proyectos por tecnología

---

### 5. 🧑‍💻 **Control de versiones con Git**
```bash
git init
git add .
git commit -m "Initial commit"
```
Sube tu proyecto a GitHub:
```bash
git remote add origin https://github.com/tuusuario/portfolio-website.git
git push -u origin main
```

---

### 6. 🚀 **Despliegue con GitHub Pages**
Desde tu repositorio en GitHub:
- Ve a **Settings > Pages**
- Selecciona la rama `main` y carpeta `/root`
- Tu sitio estará disponible en: `https://tuusuario.github.io/portfolio-website`

---

### 7. 🌐 **(Opcional) Dominio personalizado**
Compra un dominio en Namecheap, GoDaddy o similar. Luego:
- Crea un archivo `CNAME` en tu repo con el dominio
- Configura los DNS para apuntar a GitHub Pages
